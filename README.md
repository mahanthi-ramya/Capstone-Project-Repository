# Multi-Model AnswerBoard – AI Fiesta

## Overview

Multi-Model AnswerBoard – AI Fiesta is an end-to-end Artificial Intelligence and Data Engineering project consisting of three major modules:

- Data Pipeline
- Analytics Pipeline
- Support Assistant

The project demonstrates skills in web scraping, data engineering, database design, data analytics, machine learning, retrieval-augmented generation (RAG), FastAPI, and LangGraph.

---

## Module 1: Data Pipeline

### Features
- Web scraping using Requests and BeautifulSoup
- Data cleaning and preprocessing
- GBP to INR conversion
- SQLite database design
- SQL queries and joins
- Pandas integration

### Technologies
Python, Pandas, BeautifulSoup, SQLite, SQL

---

## Module 2: Analytics Pipeline

### Features
- Titanic dataset analysis
- Missing value handling
- Exploratory Data Analysis (EDA)
- Data visualization
- Classification models
- Hyperparameter tuning
- Regression analysis

### Technologies
Python, Pandas, NumPy, Seaborn, Matplotlib, Scikit-Learn

---

## Module 3: Support Assistant

### Features
- Retrieval-Augmented Generation (RAG)
- ChromaDB vector database
- LangGraph workflow
- FastAPI endpoint
- Structured JSON responses
- Docker support

### Technologies
LangGraph, ChromaDB, FastAPI, Sentence Transformers, Python
